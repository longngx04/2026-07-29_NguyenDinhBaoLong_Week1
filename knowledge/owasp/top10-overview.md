# OWASP Top 10 Overview

The OWASP Top 10 is a consensus list of the most critical web application security risks. Use it as a teaching map, not as a complete vulnerability catalog.

Week-2 knowledge focuses on risks that map to static findings and common web lessons: Injection, XSS, and integrity/deserialization failures.
