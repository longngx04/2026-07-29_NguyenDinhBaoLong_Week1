# C-002 — Run pinned OpenGrep and retain native JSON

status: done
deps: C-001
implements: FR2

## Scope

Create a scanner container with the verified OpenGrep `v1.26.0` Linux binary and checksum, add a curated checked-in Java security rule pack, and implement `make scan-opengrep`. The command must scan the pinned WebGoat submodule read-only and write only the native JSON report at the contract path.

- `results/.gitkeep`
- `.gitignore`
- `cards/C-002.md`
