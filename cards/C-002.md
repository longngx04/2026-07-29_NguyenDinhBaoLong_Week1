# C-002 — Run pinned OpenGrep and retain native JSON

status: todo
deps: C-001
implements: FR2

## Scope

Create a scanner container with the verified OpenGrep `v1.26.0` Linux binary and checksum, add a curated checked-in Java security rule pack, and implement `make scan-opengrep`. The command must scan the pinned WebGoat submodule read-only and write only the native JSON report at the contract path.

- `docker-compose.yml`
- `scanner/Dockerfile`
- `rules/opengrep/`
- `scripts/scan-opengrep.sh`
- `Makefile`
- `results/.gitkeep`
- `.gitignore`
- `cards/C-002.md`

## Verify (run these before calling the card done)

- [ ] `docker compose build scanner` completes and `docker compose run --rm scanner opengrep --version` reports `1.26.0`.
- [ ] `make scan-opengrep` exits 0 and creates `results/raw/opengrep.json`.
- [ ] `jq -e 'type == "object" and (.results | type == "array") and (.errors | type == "array")' results/raw/opengrep.json` exits 0.
- [ ] The report contains a non-negative finding count and lists only paths under `targets/webgoat/`.

## Done-evidence (world-state proof, named BEFORE building)

An operator can run `make scan-opengrep` from a clean checkout and inspect a parseable native OpenGrep JSON report at `results/raw/opengrep.json`, including the installed scanner version and its findings (if any).
