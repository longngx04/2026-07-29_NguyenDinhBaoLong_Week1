## Scope

Extend the scanner container with the checksummed FindSecBugs `1.14.0` CLI and add `make scan-findsecbugs`. The command copies the pinned WebGoat source to container-local temporary storage before Maven compilation, scans compiled classes, and writes the native SARIF report without changing the submodule or converting formats.
