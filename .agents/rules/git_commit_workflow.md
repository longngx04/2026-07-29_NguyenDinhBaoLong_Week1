# Git Commit Workflow & Approval Rule

> [!IMPORTANT]
> **NO AUTOMATIC COMMITS WITHOUT USER REVIEW**

### Rules for AI Coding Agents:
1. **Completion Notification**: When a task, phase, or feature implementation is complete and verified, DO NOT run `git commit` automatically.
2. **User Review Checkpoint**: Present the changes, file list, and verification evidence to the user.
3. **Wait for Approval**: Only execute `git commit` after receiving explicit review and approval from the user.
